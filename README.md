# AutoHotKey - zonide.ahk - My Personal AutoHotKey script.

AutoHotKey zonide.ahk:

https://github.com/Vabbajack-Sandvich/vabbajacksandvich-vs-code-bk/blob/main/ahk/zonide.ahk

Control Shift =:

To activate hot key mode.

Control Shift T:

Does time stamps 2026-06-30-11-17-37-AM

Control Shift F:

Does the zfilelist.txt find thing.

The script does other stuff and other hotkeys, but you have to look at them until I decide to write about them. These are the most useful for most people, and the other stuff is just random junk I use.

The easiest way to disable them is just to use a ; in front of the lines you don't want in the hotkeys section and recompile the test.ahk script.

zfilelist.txt finder:

This scans the search directory for your search term and adds the matches in the file names to zfilelist.txt, then outputs the file names to the output directory.

Control Shift F:

Does the zfilelist.txt find thing.

This more or less replaces Windows Find.

You can use wildcards * :

Either *.bat (file extension) or \*pho\* (find example: pho as in short for photos).

This will scan the first input window entry as the search path, the second input window as your search term, and the third input window as the output path for zfilelist.txt.

Either leave the third input box blank to use the first search path as the destination path.

You can use this batch file to move the matched filenames in zfilelist.txt by changing the zsrcpath and zdestpath to your search directory and your destination directory.

You can make copies of the batch file to make it do other commands on the zfilelist.txt matches.
