to use:

menu, tools, macro manager

click import

find the file where you downloaded it

import it

click files

select the files you want to use

if you want to do a whole folder,

hold control an press A to select all

(windows, not sure about other OS

for shortcut keys)

This is the default path for macro output:

C:\Users\USERNAME\OneDrive\Documents\Audacity\macro-output

If that isnt right, google it,

but it should be something like that.

might be some %appdata% path

but that one should be right

============================

this one has the open new window

in the macro

dont use this one for batch files

its intended for individual file use

this means it will open a new window every time

if you use this one for a bunch of files

it will open as many windows as files
