# Somewhat Easier Usage - Windows

Adding C:\ffmpeg-batch to the environment variables for easy access from the CMD prompt:

Doing it this way means the batch files will be in the path for the Command Prompt, meaning you can be anywhere in the directories and access the batch files by just typing their names.

Note: This assumes that you have WinRAR installed.

https://www.win-rar.com/download.html?&L=0

Make a folder in C:\

C:\ffmpeg-batch

Open Windows Search with the Windows key.

Type environment, click Edit the System Environment Variables.

Click the Environment Variables button.

Double-click Path.

Click the New button.

Copy and paste or type C:\ffmpeg-batch into the list entry with the cursor ticking.

Hit Enter.

Click ok on each window until they are all closed.

Download the latest revision zip file into C:\ffmpeg-batch

Right-click the zip file and click "Extract Here".

# Additional Notes:

With c:\ open you can click a batch file with a long name and hit f2 to activate the rename thing then select all, copy, then type c:\ and right click to paste the file name in the admin cmd prompt.

Makes it easy to copy and paste long batch file names and run them from c:\ from anywhere with c:\ before right clicking. That way it will always execute the batchfile when you hit the up arrow key to re-use the command if you have to.

If you are in an explorer window you can hit f4 to select the path, then control A, then control C, copy and paste a path.
